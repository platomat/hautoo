definition: Projektordner unter Versionskontrolle, auf GitHub meist „Repo“ genannt.
---

Ein Repository enthält Code, Inhalte und den Ordner `.git` mit der kompletten Historie. Öffentliche Repos darf jeder lesen; Schreibrechte hast nur du (oder dein Team).
