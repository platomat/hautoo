Die **MIT-Lizenz** (MIT License) ist eine **kurze, permissive** Open-Source-Lizenz. Du darfst den Code **nutzen, ändern und weitergeben**, musst aber den **Copyright-Hinweis** und den Lizenztext beibehalten. Es gibt keine Garantie durch die Autoren.

Offizieller Text und Erklärung: [MIT License auf opensource.org](https://opensource.org/license/mit). Auf GitHub siehst du bei vielen Repos die Lizenz unter **About** → **License** oder in einer Datei `LICENSE` im Root.

Wenn du hautoo per [Template](/glossar/template/) oder [Fork](/glossar/fork/) übernimmst, gilt die Lizenz des **Quell-Repos** für den mitgelieferten Code. Eigene Texte und Inhalte ersetzt du; Lern-Inhalte der Vorlage kannst du löschen ([Folge 024](/artikel/folge-024-github-template-privat/)).
