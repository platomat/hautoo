Ein **Template** (Vorlage) auf [GitHub](/glossar/github/) ist ein [Repo](/glossar/repository/), aus dem du mit **Use this template** (Diese Vorlage verwenden) ein **neues** Repo unter deinem Account anlegst. Du wählst dabei, ob es **öffentlich** oder **privat** sein soll.

Das ist etwas anderes als ein [**Fork**](/glossar/fork/): Ein Fork einer öffentlichen Vorlage bleibt bei GitHub öffentlich. Willst du den Quellcode nicht offen auf GitHub liegen haben, nutze das Template.

**Wichtig:** Repo **privat** heißt nur: Code und Inhalte auf GitHub sind nicht für alle lesbar. Ob deine **Website** im Internet erreichbar ist, entscheidest du beim Hosting (z. B. [Cloudflare Pages](/glossar/cloudflare-pages/)), nicht allein an diesem Schalter.
