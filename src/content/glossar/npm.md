[Node.js](/glossar/nodejs/) liefert npm mit. npm ist eine [CLI](/glossar/cli/): du startest sie im [Terminal](/glossar/terminal/). `npm install` lädt Bibliotheken in `node_modules`. `npm run dev` und `npm run build` starten den Dev-Server bzw. den [Build](/glossar/build/) für hautuu.
