# Glossar der Dokumentation

Kurze Erklärungen zu Begriffen, die in dieser Doku vorkommen. Die Website hat zusätzlich eine eigene Collection `glossar` für Fachbegriffe des Themas.

| Begriff | Bedeutung |
| --- | --- |
| **Astro** | Framework, das vor allem statische Websites erzeugt |
| **Cloudflare Pages** | Hosting, das aus einem Git-Repo gebaute Sites ausliefert |
| **Collection / Sammlung** | Gruppe gleichartiger Inhalte im CMS (z. B. `articles`) |
| **Commit** | Gespeicherter Stand einer Änderung in Git |
| **Cursor** | Code-Editor mit KI-Assistent |
| **Deploy / Deployment** | Veröffentlichen der gebauten Website |
| **Embed** | Einbetten externer Inhalte (z. B. YouTube-/Vimeo-Player) |
| **GitHub** | Plattform für Git-Repositories, Issues und Zusammenarbeit |
| **Issue** | Ticket für Aufgabe, Bug oder Idee auf GitHub |
| **Markdown** | Einfaches Textformat für Inhalte und Doku |
| **Pull Request (PR)** | Vorschlag, Änderungen in den Hauptbranch zu übernehmen |
| **Secret** | Geheimer Wert (Token, Passwort) — nie öffentlich committen |
| **Sveltia** | Git-basiertes CMS zur Pflege von Inhalten im Browser |
| **Statische Website** | Vorgebaute HTML/CSS/JS-Dateien, ohne App-Server pro Seite |

Erweiterungen willkommen — idealerweise parallel zur Website-Collection `glossar`, wo es thematisch passt.
